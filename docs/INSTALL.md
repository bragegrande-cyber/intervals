# Install Intervals on your phone

Intervals is a web app that installs like a normal app and works offline. It needs to be hosted on **HTTPS** first (for example GitHub Pages, Netlify or Cloudflare Pages: upload the whole folder as is). Opening `index.html` from a file still works on a computer, but phones can only install it from an HTTPS address.

## iPhone / iPad (Safari)
1. Open the app's HTTPS address in **Safari**.
2. Tap the **Share** button (square with an arrow).
3. Scroll down and tap **Add to Home Screen**, then **Add**.
4. Open Intervals from the home screen. It runs full screen and works without a connection after the first visit.

Sound plays even with the silent switch on (iOS 17+). If you hear nothing, tap once anywhere and check the volume buttons.

## Android (Chrome)
1. Open the app's HTTPS address in **Chrome**.
2. Tap **Install app** in the banner, or open the **⋮** menu and tap **Install app** (older versions: **Add to Home screen**).
3. Confirm with **Install**. The app appears in your app drawer.

## Updates
New versions load automatically the next time you open the app with a connection (close and reopen it once to switch over). Your progress lives on the device and is kept across updates. Deleting the app or clearing Safari/Chrome website data erases it.
